# Documentación del Frontend

La documentación del frontend está separada del código para mantener limpia la raíz del módulo.

## Carpetas

- `analisis/`: alcance, roles, inventario de pantallas, planificación y reglas del frontend.
- `informes/`: avances del equipo, estado del módulo e informes de los sprints.

El código de la aplicación permanece en `html/`, `css/` y `js/`. Las evidencias de QA se mantienen en `Frontend/qa/`.
