# Scripts de soporte

Los scripts reproducibles de validación y soporte del proyecto se almacenarán en
esta carpeta. Cada script debe documentar:

- propósito y ambiente en el que se ejecuta;
- dependencias;
- variables de entorno utilizadas;
- comando de ejecución;
- archivos que genera.

No se deben guardar aquí credenciales, datos personales, volcados de bases de
datos ni resultados temporales. Los scripts de Docker, CI, ZAP y JMeter se
incorporarán en los sprints correspondientes.
