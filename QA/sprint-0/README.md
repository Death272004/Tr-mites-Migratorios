# QA – Sprint 0: Análisis de problema

## Objetivo

Definir la estrategia inicial de calidad para una plataforma interoperable que organiza trámites migratorios y expedientes de un bufete, sin comprometer la seguridad de los datos personales.

## Riesgos iniciales

- Exposición de datos personales o documentos.
- Acceso de un usuario a expedientes ajenos.
- Requisitos legales interpretados de forma incorrecta.
- Dependencia de verificaciones externas.
- Falta de trazabilidad de las acciones.
- Datos ficticios insuficientes para validar los flujos.

## Enfoque de QA

Se definieron pruebas funcionales, de autorización, de seguridad, de integración, de rendimiento y de usabilidad. Las verificaciones externas se simularán o se harán de forma manual asistida, sin asumir acceso directo a bases gubernamentales.

## Evidencias esperadas

- Análisis del caso y mapa inicial de riesgos.
- Primer backlog e historias de usuario.
- Criterios de aceptación iniciales.
- Plan preliminar de pruebas.
- Repositorio y herramientas seleccionadas.

## Criterio de cierre

El Sprint 0 queda documentado cuando existe una estrategia de calidad, riesgos priorizados y una relación inicial entre historias, criterios de aceptación y pruebas.

## Estado

Planificación inicial documentada. La ejecución de pruebas se realiza a partir del Sprint 1.
